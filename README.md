# MASTER BUILD PROMPT — GUPTA'S AGENCY WEBSITE

Act as a senior UI/UX designer, frontend engineer, motion designer, and conversion-focused web developer. Build a complete, production-quality website for **Gupta's Agency**, a newly starting digital agency that builds websites, applications, and AI-powered automations for small businesses, startups, and growing brands.

Do not build a generic agency template. Create a distinctive, premium, polished digital experience that matches the agency's natural, earthy visual identity.

## 1. Brand identity and visual direction

Use the same visual style as the Gupta's Agency promotional poster.

**Color palette**

- Warm cream: `#F7F3E9`
- Forest green: `#173D32`
- Deep green: `#102A25`
- Soft sage: `#DCE6D2`
- Muted gold: `#D5B66A`
- Dark text: `#172522`
- White: `#FFFFFF`

Avoid neon colors, excessive gradients, glowing effects, excessive glassmorphism, and generic purple AI-themed designs.

**Typography**

- Use an elegant editorial serif font for major headlines.
- Use a clean sans-serif font for body text, navigation, buttons, and statistics.
- Create strong visual hierarchy, generous whitespace, excellent readability, and consistent spacing.

**Overall feel:** Natural, trustworthy, modern, premium, human, and approachable. It should appeal to local businesses such as salons, boutiques, pet shops, restaurants, and retail stores, as well as startups.

Requirements:

## 8. Smooth scrolling and animation system

Scrolling effects should feel premium, not distracting.

Implement:

- Smooth in-page anchor navigation.
- Subtle fade-and-rise reveals for section headings and content.
- Staggered entrance animations for service and project cards.
- Gentle image transitions and restrained hover interactions.
- A tasteful progress indicator or subtle navbar transition if it improves usability.
- Smooth transitions between the hero, services, Our Work, credibility, process, feedback, and contact sections.

Technical requirements:

- Use Framer Motion with reusable animation variants.
- Avoid attaching expensive scroll listeners to every element.
- Prefer viewport-based reveal animations.
- Do not animate large amounts of text character by character.
- Avoid excessive parallax, bouncing elements, spinning cards, cursor-following effects, and scroll-jacking.
- Respect `prefers-reduced-motion`.
- Ensure navigation, buttons, and content remain usable when animations are disabled.
- Test on mobile devices and lower-powered hardware.

The website should feel smooth because it is well engineered, not because it contains many animations.

Ensure:

- Buttons have comfortable touch targets.

- Images have appropriate alternative text.
- Forms have visible labels and useful validation.
- Keyboard navigation works.
- Reduced-motion preferences are respected.
- Contact information is easy to locate on mobile.

## 16. Final implementation and audit

Do not stop after producing a design mockup. Implement the actual website in the existing project.

Before completion:

1. Inspect the repository and reuse existing working components where appropriate.
2. Implement every section described in this prompt.
3. Verify that Our Work is prominent and populated only with truthful project information.
4. Verify all navigation links, buttons, forms, email links, phone links, and WhatsApp links.
5. Test mobile and desktop layouts.
6. Check browser console errors and failed network requests.
7. Check for broken images, missing routes, overflow, and animation issues.
8. Confirm that statistics and testimonials do not contain fabricated claims.
9. Remove temporary placeholders and unfinished UI elements, except for clearly identified optional integrations that genuinely require configuration.
10. Provide a concise implementation report describing what was built, which tests passed, and any integrations that still require configuration.

**Final design objective:** The website should look premium enough to attract serious clients, but remain honest about being a new agency. Prioritize trust, real work, clear services, direct consultation, affordability, and excellent execution over exaggerated marketing claims.
